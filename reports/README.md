# reports/：研究笔记的源文件（占位）

一份笔记有两处落点，发布时**一起换**：

| 位置 | 谁读 | 内容 |
| --- | --- | --- |
| `data/research-notes.json` | `/notes` 页面 | 标题、副标题、难度、`published` 开关、markdown 正文 |
| `note-logs/note-{1..4}.json` | `GET /note-log/{x}` | AI 学习伙伴写的原始日志（只读，原样返回） |

## 发布一份笔记

1. 在 `reports/note-3.md` 写正文，结构固定：

   ```markdown
   ## 摘要
   （只写这一段会出现在页面上）

   ## 一、
   ## 二、
   ## 三、

   ## 四、
   （这一节套「手写体便签块」样式，给孩子照着抄）

   ## 给 Agent 的指令
   （不会展示，写维护者才知道的操作）

   ## 附录
   （不会展示：原始数据、长表格、复现命令）
   ```

2. 把 markdown 原文塞进 `data/research-notes.json` 对应条目的 `markdown` 字段，
   并把 `published` 改成 `true`；
3. 刷新 `/notes` 即可（服务端渲染，不需要重启）。

> 页面只渲染 `## 摘要` ~ `## 附录` 之间的部分，并强制剥掉「给 Agent 的指令」整节。
